# Mariano Rama — Portfolio

Portfolio personal, construido a mano con HTML/CSS/JS (sin frameworks) y desplegado con GitHub Pages.

🔗 **Sitio en vivo:** https://marianorama.github.io

## Qué muestra

Cuatro proyectos reales, cada uno con una demo visual interactiva (capturas con datos de ejemplo, click para ampliar):

- **Estudio JF** — sistema de gestión para un estudio contable real, en producción (Java/Spring Boot, React, AWS)
- **Obligatorio App** — marketplace de compraventa full stack (Node.js, MongoDB, JWT)
- **MoveTrack** — app Android de seguimiento de actividades (Ionic + Capacitor + Leaflet)
- **Sistema de Peajes** — simulación de gestión de peajes en tiempo real (Spring Boot + SSE)

## Detalles técnicos

- Bilingüe (EN/ES) con toggle de idioma, sin librerías externas de i18n
- Tema único dibujado a mano ("blueprint" / plano técnico)
- Sin dependencias de build: es un solo archivo `index.html` autocontenido
